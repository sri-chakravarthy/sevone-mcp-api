SevOne MCP Server: Bridging AI Agents and Network Observability

Overview

The SevOne MCP Server is an open-source Python project that connects AI agents — specifically IBM's Bob AI — to SevOne Network Management System (NMS) through the Model Context Protocol (MCP). It transforms natural-language queries from an AI agent into authenticated, structured REST API calls against a live SevOne environment, and returns structured JSON results ready for reasoning and summarisation.

Problem It Solves

Network operations teams routinely query observability platforms — checking device health, reviewing alerting policies, inspecting performance indicators — but doing so requires navigating complex REST APIs with bearer-token authentication, multi-level filter schemas, and pagination. This project abstracts all of that into a clean MCP tool layer, letting an AI agent handle network queries in plain English without exposing API complexity to the end user.

Architecture

Bob AI Agent → MCP Protocol (stdio / SSE) → SevOne MCP Server
    ├── Auth Layer   (Fernet-encrypted credentials, auto token refresh)
    ├── API Client  (async HTTPS to SevOne REST API)
    └── Tool Layer  (10 domain-specific MCP tools)
→ SevOne NMS

The server ships with two transports — stdio for local agent integration and Server-Sent Events (SSE) for remote HTTP deployments — making it suitable for both desktop and production environments.

Key Technical Features

Credentials are encrypted at rest using Fernet symmetric encryption. Bearer tokens are acquired on first use and silently refreshed on expiry, so no tool call ever exposes raw passwords. All I/O is fully asynchronous (async/await), keeping the server non-blocking under concurrent requests.

The tool layer covers ten domain-specific operations:

get_device_details
Devices by name, ID, or group
get_object_details
Monitored objects per device
get_indicator_details
Performance indicator data
get_alerting_policy_details
Alert policies by severity
get_device_metadata_ids
Namespace and attribute IDs
create_device_group
Hierarchical group creation
add_devicegroup_rules
Automated device classification
run_api_endpoint
Generic pass-through for any endpoint

Impact

By exposing SevOne's capabilities as MCP tools, the project enables AI-driven network operations without custom scripting per query. An operator can ask "Show me all critical alerting policies for the West Coast device group" and receive a structured, actionable answer — backed by live data — in seconds. The architecture is extensible: adding a new SevOne endpoint requires only a new tool module and a single registration line in the server.
